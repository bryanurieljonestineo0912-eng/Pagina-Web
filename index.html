Practica 1: Crear Repositorio en Github

Curso de Control de Versiones con Git y GitHub

Objetivo Requisitos Pasos Resultado

Introducción

Esta práctica tiene como finalidad aprender los conceptos básicos de Git y GitHub, incluyendo la creación de repositorios, la gestión de ramas y el despliegue automático de páginas web mediante GitHub Pages.

📌 Nota importante: Esta es una práctica académica para estudiantes que están aprendiendo a trabajar con sistemas de control de versiones.

Objetivo de la Práctica

Al finalizar esta práctica, el estudiante será capaz de:

  • Crear un repositorio en GitHub
  • Entender el flujo básico de Git (commit, push, pull)
  • Configurar GitHub Pages para desplegar una página web
  • Usar GitHub Projects para planificación con Kanban
  • Automatizar el despliegue de contenido web

Requisitos Previos

  • Tener una cuenta en GitHub (https://github.com)
  • Git instalado en tu computadora
  • Conocimientos básicos de terminal/línea de comandos
  • Un editor de texto (Visual Studio Code, Notepad++, etc.)

Pasos de la Práctica

1. Crear el Repositorio

Primero, debes crear un nuevo repositorio en GitHub. Para esto:

  • Inicia sesión en tu cuenta de GitHub
  • Haz clic en el icono "+" en la esquina superior derecha
  • Selecciona "New repository"
  • Dale un nombre descriptivo (ej: "Practica1-Crear-Repositorio-en-Github")
  • Agrega una descripción
  • Marca la opción "Public" para que sea visible
  • Haz clic en "Create repository"

2. Clonar el Repositorio

Después de crear el repositorio, debes clonarlo en tu computadora:

git clone https://github.com/tu-usuario/tu-repositorio.git
cd tu-repositorio

3. Crear Archivos Iniciales

Es recomendable crear los archivos principales del proyecto:

  • README.md: Descripción del proyecto
  • .gitignore: Archivos a ignorar por Git
  • index.html: Página web principal

4. Hacer Commit y Push

Para guardar tus cambios en GitHub:

git add .
git commit -m "Commit inicial"
git push origin main

5. Configurar GitHub Pages

Para desplegar automáticamente tu página web:

  • Ve a "Settings" en tu repositorio
  • En el menú izquierdo, selecciona "Pages"
  • En "Source", selecciona tu rama (main)
  • Espera a que GitHub despliegue tu página

6. Crear un Tablero Kanban

Usa GitHub Projects para organizar tus tareas:

  • Ve a la pestaña "Projects" en tu repositorio
  • Crea un nuevo proyecto con plantilla Kanban
  • Agrega columnas: "Por hacer", "En progreso", "Completado"
  • Crea tareas para cada fase del proyecto

Conceptos Clave Aprendidos

Concepto Descripción
Repositorio Carpeta que almacena el código y el historial de cambios
Commit Fotografía del estado actual del proyecto
Push Enviar cambios locales al repositorio remoto
Pull Descargar cambios del repositorio remoto
Branch Rama independiente del proyecto para trabajar en paralelo
GitHub Pages Servicio para hospedar sitios web estáticos gratis

Resultado Esperado

Al terminar esta práctica, tendrás:

  • ✅ Un repositorio GitHub funcional y público
  • ✅ Una página web desplegada con GitHub Pages
  • ✅ Un tablero Kanban para organizar tareas
  • ✅ Conocimiento sobre control de versiones
  • ✅ Experiencia con automatización CI/CD básica
🎯 Meta: Comprender cómo los desarrolladores profesionales utilizan herramientas modernas para colaborar y desplegar código en producción.
